# online-shop-yii2

**Bài quá trình lần 2 – Yii2 CRUD Giỏ hàng, Đơn hàng**

Dự án được xây dựng dựa trên Yii2 Basic Project Template.

## Giới thiệu

Website bán hàng trực tuyến được phát triển bằng PHP và Yii2 Framework.
Dự án hướng đến việc xây dựng các chức năng quản lý sản phẩm,
giỏ hàng và đơn hàng.

## Cấu trúc thư mục

- `assets/`: Quản lý tài nguyên giao diện.
- `commands/`: Các lệnh console.
- `config/`: Cấu hình ứng dụng.
- `controllers/`: Xử lý yêu cầu từ người dùng.
- `models/`: Mô hình dữ liệu và nghiệp vụ.
- `runtime/`: Dữ liệu phát sinh khi chạy.
- `tests/`: Các tệp kiểm thử.
- `views/`: Giao diện người dùng.
- `web/`: Điểm truy cập và tài nguyên web.

## Yêu cầu

- PHP 8.2 trở lên.
- Composer.
- Máy chủ web và cơ sở dữ liệu phù hợp với cấu hình dự án.
